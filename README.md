📊 Coca-Cola Sales Analysis Using Excel
📌 Project Overview

This project focuses on analyzing Coca-Cola retail sales data across multiple U.S. retailers to identify sales patterns, profitability trends, and regional performance. The objective is to transform raw transactional data into actionable insights that support business decision-making.

🎯 Business Objectives
Analyze sales performance across retailers and regions
Identify high-performing and underperforming markets
Evaluate pricing impact on profitability
Detect seasonal trends and peak sales periods
Provide data-driven recommendations for improving sales performance
🛠 Tools & Technologies
Microsoft Excel
Pivot Tables
Slicers
Data Cleaning
Charts & Visualizations
📂 Dataset Description

The dataset contains multi-sheet retail sales data including:

Retailer Name
Region
Units Sold
Total Sales
Price per Unit
Operating Margin
Monthly Sales Data
🔧 Data Preparation Steps
Standardized column names
Removed duplicates and corrected inconsistent values
Handled missing and incorrect data entries
Converted date and numeric columns into proper formats
Structured metrics for accurate analysis
📊 Analysis Performed
Sales & Profitability Analysis
Compared sales and profit performance across retailers
Identified top-performing regions
Evaluated pricing impact on total revenue
Time-Based Analysis
Analyzed monthly sales trends
Identified seasonal demand patterns
Tracked profitability changes over time
📈 Dashboard Features
Retailer Comparison Charts
Monthly Sales Trend Analysis
Regional Sales Heatmaps
Interactive Filters Using Slicers
KPI-based Summary Views
